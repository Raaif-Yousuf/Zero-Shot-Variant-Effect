# Sanity checks

Positive controls for the negative benchmark result (see `results/metrics_brca1.md`, `results/metrics_clinvar.md`): if the models and pipeline work at all, they should recover a masked base from real genomic sequence far above chance and score real sequence more likely than a composition-matched shuffle. Both checks below hold. What the LLR scores actually correlate with instead, using only the scores already committed to `results/scores/`, is in the third section.

All positions/windows are seeded (`--seed 0`) draws from hg19 chr17, restricted to windows containing no N bases. Generated by `scripts/sanity_checks.py`.

## a. Nucleotide Transformer (nt-v2-50m) masked-token recovery

300 seeded positions in chr17, each inside an ACGT-only 1024 bp window. The 6-mer token covering the position is masked and read back from a single forward pass. Chance for the 6-mer is 1/4096 (0.000244); chance for the center base alone is 1/4.

| metric | value | n |
| --- | --- | --- |
| top-1 accuracy, masked 6-mer (over the 4,096 clean 6-mers) | 0.1267 | 300 |
| top-1 accuracy, center base only | 0.4333 | 300 |
| mean log P(reference 6-mer), nats | -7.6302 | 300 |


## b. HyenaDNA (hyenadna-small-32k) real versus shuffled

200 seeded, ACGT-only, 1024 bp chr17 windows. Each window's dinucleotide-preserving shuffle (Altschul-Erikson algorithm; see `scripts/_sanity_common.dinucleotide_shuffle`) is scored alongside the real window in the same forward pass, causal mode, mean per-base log-likelihood converted to bits per base (lower is better/more predictable).

| metric | value | n |
| --- | --- | --- |
| mean bits/base, real window | 1.5896 | 200 |
| mean bits/base, shuffled window | 1.9406 | 200 |
| mean paired difference (shuffled - real), bits/base | 0.351 | 200 |
| fraction of windows real scores higher than its shuffle | 1.0 | 200 |
